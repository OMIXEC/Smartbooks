# Smartbooks repository instructions

Use Smartbooks for the product name and `sbs` for the command. Use Smartbooks terminology in file paths, branches, commit messages, issues, pull requests, comments, release notes, and examples. Keep external product names, comparisons, artifact URLs, and unpacked third-party material in private working notes. Describe desired behavior in terms of Smartbooks capabilities.

Write agent instructions and integrations for Smartbooks interfaces. Preserve license notices and attribution for any approved third-party material. Keep existing library IDs, citations, and continuation contracts compatible when changing readers or storage.

Run `npm run typecheck`, `npm run build`, and `npm test` before publishing changes to the CLI or its integrations. Use synthetic or openly licensed fixtures.
